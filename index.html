動作の流れ / 동작 방식
  • ① 入場QRでチェックインした人だけが候補に出ます — 店の外・別の日の人は出てきません입장 QR로 체크인한 사람만 후보에 뜹니다 — 매장 밖·다른 날 사람은 안 나옵니다
  • ② プロフィールはニックネーム・年齢・言語・好きなジャンル・今いるゾーン（フロア / B卓）まで닉네임·나이·언어·좋아하는 장르·지금 있는 존까지 표시
  • ③ ✕ / ♥ で選び、両想いで初めてマッチ — 連絡先は交換しません✕ / ♥로 고르고 서로 좋아요일 때만 매칭 — 연락처는 교환하지 않습니다
  • ④ マッチ後はアプリ内チャット、そのままテーブルに招待できます → 04 の TABLE JOIN（割り勘）へ매칭되면 앱 내 채팅, 그대로 테이블 초대 → 04의 TABLE JOIN(더치페이)으로
  • ⑤ 退店から24時間で会話は自動終了 — 「その夜だけ」に閉じることが安全装置になります퇴장 후 24시간이면 대화 자동 종료 — 「그날 밤만」으로 닫는 것이 안전장치
  • 本人確認・通報 / ブロック・スクリーンショット通知を標準装備본인확인·신고/차단·스크린샷 알림 기본 탑재
なぜこの機能が中心なのか
マッチングは日本ですでに日常です。ただし既存アプリは「会うまで」で終わり、店の売上にはつながりません。
MU:IN は「その夜・同じ店内」だけに絞ることで、出会いを相席 → 卓 → ボトルへ直結させます。 集客・滞在時間・客単価が同時に上がる、クラブ側にしか作れない設計です。 매칭은 일본에서 이미 일상입니다. 다만 기존 앱은 「만나기까지」에서 끝나고 매장 매출로는 이어지지 않습니다. MU:IN은 「그날 밤·같은 매장」으로만 좁혀서, 만남을 합석 → 테이블 → 보틀로 직결시킵니다. 집객·체류시간·객단가가 동시에 올라가는, 클럽만이 만들 수 있는 설계입니다.
